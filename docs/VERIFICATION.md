# 검증 기록

검증일: **2026-10-29 (한국 시간)** / 버전: **0.1.0**

## 환경

- Windows, Java 25, Gradle 9.5.1
- Minecraft Java 26.2 / Fabric Loader 0.19.5 / Fabric API 0.160.0+26.2
- 이 저장소의 별도 개발 프로필 및 새 크리에이티브 싱글플레이 월드
- OpenGL / NVIDIA RTX 3060 / 856×512 창

## 완료한 검사

| 항목 | 결과 |
| --- | --- |
| `gradlew build --offline` | 통과, 설치용 및 소스 JAR 생성 |
| 표식 만료·페이드·같은 위치 재조작 | 자동 검사 통과 |
| 최신 조작 순서·가장 오래된 항목 제거 | 자동 검사 통과 |
| 반복 10,000회에서도 최대 개수 유지 | 자동 검사 통과 |
| 열린 상자의 타이머 유지·닫은 뒤 만료 | 자동 검사 통과 |
| 취소/월드 변경용 초기화·투명도 범위 | 자동 검사 통과 |
| 개발 클라이언트 초기화·Mixin 적용·월드 진입 | 정상, 관련 크래시 없음 |
| 중계기 설치 | 실제 화면에서 초록 윤곽 확인 |
| 설치한 중계기를 우클릭해 단계 변경 | 실제 화면에서 단계 변화와 노란 윤곽 확인 |
| 중계기 제거 | 사라진 중계기의 낮은 형태로 빨간 윤곽이 남는 것 확인 |
| 시간 경과 후 제거 표식 소멸 | 실제 화면에서 확인 |
| 상자 설치 | 실제 상자 형태의 초록 윤곽 확인 |
| 상자를 열고 2.5초 이상 유지한 뒤 닫기 | 닫은 직후 하늘색 윤곽 확인 |
| H로 끄기 후 휠 클릭 | OFF 안내 및 색상 윤곽 미표시 확인 |
| H로 다시 켜기 | ON 안내 확인 |
| F1 상태에서 휠 클릭 | HUD가 없는 화면에서도 보라색 상자 윤곽 확인 |

## 아직 실기 검증하지 않은 범위

- 실제 멀티플레이 및 보호 구역의 서버 거절/지연
- 여러 상자를 빠르게 연달아 여는 실제 입력(표식 순서와 개별 타이머는 자동 검사로 확인)
- 생존 모드에서 채굴 완료, 모험/관전자 모드
- 문·통·화로·반 블록 등 모든 개별 블록의 회귀 검사
- 다른 모드, 셰이더, Vulkan 및 실제 방송 프로그램의 화면 캡처
- 설정 파일 수동 변경·재시작, 모든 해상도와 GUI 배율

개발 실행에서 기본 게임의 프로필 인증과 Windows 성능 카운터 경고가 기록되었습니다.
검증 중 Show Interaction의 Mixin 오류나 렌더링 예외는 발생하지 않았습니다.

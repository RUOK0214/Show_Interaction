# 검증 기록

검증일: **2026-10-29 (한국 시간)** / 개발 버전: **0.3.0** / 공개 버전: **0.2.1**

## 0.3.0 선·색 및 상호작용 로그 (개발 중)

- 반응별 선 두께 1~15, 색, 설정 초안의 독립성, 취소/저장 실패 시 복원 모델 검사 통과.
- 이전 공통 두께·색 이전, 새 반응별 값 우선 처리, 잘못된 값 복구, JSON 저장·재읽기 검사 통과.
- 로그 기록은 표시 설정과 독립적이며 반응별 켜기/끄기와 저장·재읽기 검사 통과.
- 시간·블록·좌표·월드·차원·변경 전후 정보를 가진 불변 로그, 최신순, 같은 위치의 연속 기록, 정확한 되돌림 대상 검사 통과.
- 최근 1,000건 제한, 백그라운드 저장 중 추가된 기록의 정상 종료 저장, 재시작 후 복원, 손상 파일 보존 검사 통과.
- 로컬 `build` 및 실제 JAR의 버전·라이선스·번역·아이콘·의존성 미포함 검사 통과.
- 선·색 화면은 856×512 개발 게임에서 한국어 배치와 기본값 표시를 확인했습니다. 이후 Esc로 컴퓨터 사용이 중단되어 당시 조절·저장 실기 검증은 완료하지 않았습니다.
- 로그 기능과 두께 15의 실제 입력·저장·월드 렌더링은 아직 화면 검증 전입니다. 아래 0.2.x의 결과를 이번 버전의 전체 회귀 검사로 간주하지 않습니다.

## 0.2.1 배포 준비 (공개 게시하지 않음)

- 사용자가 선택한 MIT 라이선스 전문과 Copyright (c) 2026 RUOK0214 고지 추가.
- Fabric 메타데이터에 MIT·256×256 아이콘·프로젝트/소스/문제 보고 링크 추가.
- 한국어·영어 Mod Menu 요약과 상세 설명, 선택적인 설정 버튼 연동 추가.
- 모드 목록에서 연 설정창을 닫으면 부모 모드 목록으로 복귀하도록 변경.
- 설치 JAR, 소스 JAR, 사용 안내, 변경 기록, 라이선스, 제3자 고지, 검증 기록과 SHA-256을 묶는 로컬 배포 작업 추가.

| 항목 | 결과 |
| --- | --- |
| 기본 빌드 및 모델 검사 | 통과 |
| 실제 JAR의 버전·MIT 전문·번역·아이콘·Mod Menu 선택 의존성 | 자동 검사 통과 |
| Minecraft/Mod Menu/의존성 JAR·사용자 설정 등이 배포 JAR에 섞이지 않는지 | 자동 검사 통과 |
| Mod Menu 20.0.2를 포함한 개발 게임 실행 | 정상 |
| Mod Menu 목록 및 상세 표시 | 아이콘·Show Interaction 0.2.1·RUOK0214·Client·MIT·영어 설명·링크 확인 |
| Mod Menu 설정 버튼 | 기존 설정창 진입 확인 |
| 설정창에서 모드 목록으로 복귀 | 실제 화면에서 확인 |
| Mod Menu가 없는 별도 개발 프로필 | 51개 모드 목록에 Mod Menu 없음; 클라이언트 초기화와 기본 설정 파일 생성 확인 |

한국어 Mod Menu 설명은 리소스와 자동 검사로 확인했으며, 이번 실행에서는 게임 언어가 일본어/영어여서
영어 대체 설명을 확인했습니다. 한국어 모드 목록의 직접 화면 검증, 게임이 설치된 일반 사용자 프로필에서
배포 JAR를 직접 넣는 실행, 멀티플레이 및 모든 렌더링 조합은 아직 미검증입니다.
기존 개발 환경의 Realms 인증 및 Windows 성능 카운터 경고 외에 모드 연동 오류는 확인되지 않았습니다.

## 0.2.0 명령어 및 설정창

- 전용 키 등록과 H 처리 및 해당 번역 항목 제거. `/showinteraction` 클라이언트 명령어 추가.
- 전체 표시, 투명도 0~100%, 다섯 반응별 켜기/끄기·0.5~10초 시간 슬라이더 추가.
- 저장 후 적용/취소, 저장 실패 시 기존 설정 복원, 임시 파일 교체 방식 저장 추가.
- 반응별 표식 수명과 열린 상자의 독립 시간 보존, 전체 투명도 곱셈 적용.
- 일반 사용은 응답을 확인한 뒤 분류하여, 꺼 둔 상자/조절 반응이 먼저 확인 색상으로 보이지 않도록 함.

| 항목 | 결과 |
| --- | --- |
| 0.2.0 빌드 및 자동 검사 | 통과 |
| 반응별 독립 만료·상자 유지 시간·같은 위치의 새 시간 적용 | 자동 검사 통과 |
| 전체/개별 전환, 투명도 0/35/100%, 초안 분리 및 적용 | 자동 검사 통과 |
| 이전 공통 시간의 다섯 반응 이전·누락/잘못된 값 처리 | 자동 검사 통과 |
| `/showinteraction` 실행 | 한국어 설정창 정상 표시, 채팅에 의해 즉시 닫히지 않음 |
| 856×512 창에서 설정창 배치 | 다섯 반응과 저장/취소 버튼이 모두 표시됨 |
| 투명도 50%, 설치 6초, 제거 끄기 변경 및 저장 | 실제 입력으로 확인; 설정 파일에도 정확히 기록됨 |
| 저장한 설정으로 중계기 설치 | 50% 투명도가 적용된 초록 윤곽 확인 |
| 제거 반응을 끈 상태에서 중계기 제거 | 빨간 윤곽이 표시되지 않음 |
| 설정창 재진입 | 투명도·개별 전환·시간 유지 확인 |
| 전체 표시를 끈 초안을 취소 | 설정 파일의 기존 전체 켜짐 및 나머지 값 유지 확인 |

0.2.0에서 전체 끄기 저장 후 재진입, 재시작 후 설정 복원, 모든 반응의 실제 시간 계측,
Esc 입력, 저장 실패 상황 및 멀티플레이 실기 검증은 아직 하지 않았습니다.
이전 버전의 결과를 새 버전의 전체 회귀 검사로 간주하지 않습니다.

## 아직 실기 검증하지 않은 범위

- 실제 멀티플레이 및 보호 구역의 서버 거절/지연
- 여러 상자를 빠르게 연달아 여는 실제 입력(표식 순서와 개별 타이머는 자동 검사로 확인)
- 생존 모드에서 채굴 완료, 모험/관전자 모드
- 문·통·화로·반 블록 등 모든 개별 블록의 회귀 검사
- 다른 모드, 셰이더, Vulkan 및 실제 방송 프로그램의 화면 캡처
- 설정 파일 수동 변경·재시작, 모든 해상도와 GUI 배율

개발 실행에서 기본 게임의 프로필 인증과 Windows 성능 카운터 경고가 기록되었습니다.
검증 중 Show Interaction의 Mixin 오류나 렌더링 예외는 발생하지 않았습니다.

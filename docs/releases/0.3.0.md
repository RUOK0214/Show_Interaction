# Show Interaction 0.3.0

## 새 기능

- 설치·제거·조절·상자 열기·확인마다 **선 두께와 색**을 따로 설정합니다.
- 선 두께는 **1~15, 0.5 단위**입니다. RGB 슬라이더, 색 코드 입력, 미리보기와 반응별 기본값 복원을 제공합니다.
- 설정창의 **로그 보기**에서 날짜·시간·상호작용 목록을 확인하고 항목을 선택하면 블록, 좌표, 월드/차원, 변경 전후 상태를 볼 수 있습니다.
- 각 반응의 **기록** 스위치로 로그를 개별 제어합니다. 강조 표시를 꺼도 기록이 켜져 있으면 로그를 남깁니다.
- 최근 **1,000건**을 해당 게임 프로필에 저장하며 게임 재시작 후에도 유지합니다.
- 기존 색·공통 선 두께·표시 여부·시간 설정을 보존해 새 형식으로 이전합니다.

## 사용

`/showinteraction` 또는 선택 사항인 Mod Menu의 설정 버튼으로 설정창을 여세요.
‘선·색’ 화면에서 조절 후 ‘완료’를 누르고, 원래 설정창에서 **저장 후 적용**을 누르세요.
기록 스위치도 저장 후 적용됩니다. 로그 파일은 `config/show-interaction-log.json`이며 다른 곳으로 전송하지 않습니다.

## 설치

**Minecraft Java 26.2 · Java 25 이상 · Fabric Loader 0.19.5 이상 · Fabric API 0.160.0+26.2 또는 26.2용 호환 버전**.
`show-interaction-0.3.0.jar`를 `mods` 폴더에 넣고 이전 Show Interaction JAR는 함께 넣지 마세요.
Mod Menu 20.0.2는 선택 사항입니다. 서버 설치와 별도 단축키는 필요하지 않습니다.
Assets에서 **`show-interaction-0.3.0.jar` 하나만** 받으세요. GitHub가 자동 제공하는 `Source code` 압축 파일은 설치용이 아닙니다.

## English

Configure each reaction's line width (1–15 in 0.5 steps) and color with RGB/hex controls and a preview.
Browse the interaction log by timestamp and action; select an entry for block, coordinates, world, dimension and before/after details.
Per-reaction logging is independent of highlights. The latest 1,000 events are stored locally across restarts.
Open `/showinteraction`, edit Style, then choose Done and Save and apply. Legacy settings are migrated automatically.

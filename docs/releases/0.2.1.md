# Show Interaction 0.2.1

방금 설치·제거·조절·열기·확인한 블록을 잠시 색상 윤곽으로 강조하는 클라이언트 모드입니다.
중계기 단계 변경이나 상자 확인 위치를 방송·녹화 시청자가 따라가기 쉽게 보여 줍니다.

## 설치

1. **Minecraft Java 26.2**, **Java 25 이상**, **Fabric Loader 0.19.5 이상**을 사용하세요.
2. 아래 Assets의 **`show-interaction-0.2.1.jar`**와 **26.2용 Fabric API 0.160.0+26.2 또는 호환 버전**을 게임의 `mods` 폴더에 넣으세요.
3. 게임에서 **`/showinteraction`**을 입력하면 설정창이 열립니다.

**Mod Menu 20.0.2(26.2용)는 선택 사항**이며, 설치하면 모드 목록의 설정 버튼을 사용할 수 있습니다.
서버에는 설치할 필요가 없습니다. 이전 Show Interaction JAR와 새 버전을 동시에 넣지 마세요.
GitHub의 **Source code**, `-sources.jar`, 배포 ZIP 자체는 `mods` 폴더에 넣지 않습니다.

## 주요 기능

- 설치·제거·조절·상자 열기·확인을 다른 색으로 표시하고, 가장 최근 조작을 더 선명하게 표시합니다.
- 전체 켜기/끄기, 투명도, 반응별 켜기/끄기 및 표시 시간(0.5~10초)을 설정합니다.
- 상자를 열어 둔 동안 표시를 유지하고, 닫은 뒤 설정한 시간 동안 남깁니다.
- 전용 단축키가 없으며, 한국어·영어 설정과 Mod Menu 설명을 제공합니다.

## 검증 범위

자동 빌드, 표식·설정 모델 검사, JAR·ZIP 구성 및 검증값 검사를 통과한 파일을 배포합니다.
개발 환경에서 블록 설치·제거, 중계기 조절, 상자 열기와 설정 화면을 확인했으며,
0.2.1은 Mod Menu를 포함하거나 제외한 실행을 확인했습니다.
**일반 게임 프로필에 배포 JAR 직접 설치, 실제 멀티플레이, 셰이더·Vulkan 조합은 아직 미검증**입니다.
자세한 범위는 [검증 기록](https://github.com/RUOK0214/Show_Interaction/blob/v0.2.1/docs/VERIFICATION.md)을 참고하세요.

문제는 [GitHub Issues](https://github.com/RUOK0214/Show_Interaction/issues)에 게임·모드 버전과 재현 방법을 적어 알려 주세요.

## English

Show Interaction briefly outlines the blocks you just placed, broke, adjusted, opened or inspected.
Install `show-interaction-0.2.1.jar` with Fabric API for **Minecraft Java 26.2** and **Fabric Loader 0.19.5+**; **Java 25+** is required.
Open settings with `/showinteraction`, or use the optional **Mod Menu 20.0.2** configuration button.
Client-side only; no server installation or dedicated hotkey is needed.
Configure global visibility, transparency, and visibility/duration for each reaction.
Do not install the source JAR, GitHub source archives or distribution ZIP as mods.
Direct installation into a normal game profile, multiplayer, shaders and Vulkan have not yet been verified.

Show Interaction 0.3.0 — Minecraft Java 26.2 / Fabric
제작 / Author: RUOK0214 · License: MIT

[한국어]
1. Minecraft Java Edition 26.2에 Fabric Loader 0.19.5 이상을 설치합니다.
2. 해당 프로필의 mods 폴더에 show-interaction-0.3.0.jar와
   26.2용 Fabric API 0.160.0+26.2 또는 호환 버전을 넣습니다.
3. 이전 Show Interaction JAR가 있다면 새 버전과 동시에 넣지 마세요.
4. 게임에서 /showinteraction을 입력하여 설정창을 엽니다.

전체 켜기/끄기, 투명도, 반응별 켜기/끄기·표시 시간·선 두께(1~15)·색·로그 기록을 설정할 수 있습니다.
반응 옆 선·색에서 조절하고 완료 후 원래 설정창에서 저장 후 적용을 누르세요.
‘저장 후 적용’으로 저장하며 ‘취소’나 Esc는 변경 전 설정을 유지합니다.
로그 보기에서 항목을 선택하면 위치와 변경 전후 정보를 볼 수 있습니다.
반응별 기록은 강조 표시와 독립적이며 최근 1,000건을 로컬에 저장합니다.
전용 단축키는 없습니다. 서버 설치는 필요하지 않습니다.
Mod Menu 20.0.2(26.2용)는 선택 사항입니다. 설치하면 모드 목록의 설명과
설정 버튼도 사용할 수 있습니다. Mod Menu가 없어도 명령어는 작동합니다.

이 ZIP 자체, developer 폴더의 -sources.jar, 문서 파일은 mods에 넣지 마세요.
Java 25 이상이 필요합니다. Bedrock, Forge/NeoForge, 다른 게임 버전은 지원하지 않습니다.
멀티플레이, 셰이더 및 Vulkan의 실기 검증은 아직 완료하지 않았습니다.

[English]
Install Fabric Loader 0.19.5+ for Minecraft Java 26.2, then place
show-interaction-0.3.0.jar and Fabric API 0.160.0+26.2 (or a compatible
26.2 build) in that profile's mods folder. Java 25+ is required.
Remove older Show Interaction JARs from the active mods folder when updating.
Use /showinteraction to open settings. Each reaction has a Style button for
line width (1–15) and color. Choose Done, then Save and apply in the parent screen.
View log lists recent interactions; select one for details. Each reaction has an
independent logging toggle. The latest 1,000 events are stored locally. No dedicated hotkey or server install.
Mod Menu 20.0.2 for 26.2 is optional and provides a mod-list configuration button.
Do not install this ZIP, documentation or the developer/-sources.jar as mods.
Multiplayer, shaders and Vulkan have not yet been fully tested.

# Show Interaction

마인크래프트 방송·녹화에서 **방금 건드린 블록의 윤곽을 잠시 반짝이게 하는 클라이언트 전용 모드**입니다.
중계기 단계를 잘못 바꿨을 때나 여러 상자를 연달아 확인할 때, 시청자가 조작한 위치를 따라올 수 있습니다.

**[다운로드: Show Interaction 0.2.1](https://github.com/RUOK0214/Show_Interaction/releases/tag/v0.2.1)** · [문제 보고](https://github.com/RUOK0214/Show_Interaction/issues) · [MIT 라이선스](LICENSE)

릴리스의 **Assets**에서 `show-interaction-0.2.1.jar`를 받으세요. `Source code`와 `-sources.jar`는 설치용이 아닙니다.

## 실행 환경 및 설치

- Minecraft **Java Edition 26.2**
- Fabric Loader **0.19.5 이상**
- Fabric API **0.160.0+26.2** 또는 26.2용 호환 버전
- Java **25 이상**

Fabric으로 실행하는 게임 프로필의 `mods` 폴더에 **`show-interaction-0.2.1.jar`**와 Fabric API를 넣으세요.
`-sources.jar`는 개발용이며 설치 파일이 아닙니다. Forge/NeoForge, Bedrock, 다른 마인크래프트 버전은 지원하지 않습니다.
업데이트할 때는 이전 Show Interaction JAR와 새 버전을 동시에 넣지 마세요.

[Mod Menu](https://modrinth.com/mod/modmenu) **20.0.2(26.2용)**를 선택적으로 설치하면 모드 목록에서 설명·아이콘·제작자·MIT 라이선스를 확인하고 설정 버튼을 사용할 수 있습니다.
Mod Menu가 없어도 `/showinteraction` 명령어와 강조 기능은 작동합니다.

서버에는 설치할 필요가 없습니다. 강조 표시는 모드를 설치한 플레이어의 화면에만 나타나며, 해당 화면을 캡처하는 방송·녹화에도 보입니다.
다른 플레이어에게 표식을 전송하거나 블록의 실제 동작을 바꾸지 않습니다.

## 표시 방식

| 행동 | 기본 색상 | 표시 위치 |
| --- | --- | --- |
| 블록 설치 | 초록색 | 실제 설치된 블록 |
| 블록 제거 완료 | 빨간색 | 제거되기 전 블록의 윤곽 |
| 중계기 단계·레버·문 등 상태 조절 | 노란색 | 변경된 블록 |
| 상자·통·화로 등 열기 | 하늘색 | 서버가 열어 준 보관함·작업대의 클릭한 블록 |
| 일반 사용 / 휠 클릭으로 블록 확인 | 보라색 | 상호작용한 블록 |

- 기본 **2.5초**, 부드럽게 반짝이다 마지막에 흐려지며 사라집니다. 반응별로 시간을 따로 설정할 수 있습니다.
- 가장 최근 블록을 더 진하고 굵게 표시합니다. 이전 표시는 각자 남은 시간 동안 유지됩니다.
- 같은 블록을 다시 조작하면 타이머가 갱신됩니다.
- 상자 화면을 열어 둔 동안 표식을 유지하고, 닫은 뒤에는 ‘상자 열기’에 설정한 시간만큼 남깁니다.
- 중계기·반 블록·상자 등은 실제 선택 형태를 따라 표시합니다. 제거 시에는 이전 형태를 보존합니다.
- 벽 뒤로 투시하지 않습니다. 플레이어에게 보이는 윤곽만 표시합니다.
- 단순히 바라보거나 블록을 캐기 시작하는 것만으로는 표시하지 않습니다.
- 주변 회로의 자동 변화, 다른 플레이어의 조작, 명령어로 바뀐 모든 블록을 추적하지 않습니다.

전용 단축키는 없습니다. **`F1`로 HUD를 숨겨도 기본적으로 강조는 표시됩니다.**

## 설정창

채팅에 **`/showinteraction`**을 입력하면 설정창이 열립니다. 클라이언트 명령어라 서버 관리자 권한이나 치트 허용이 필요하지 않습니다. 전체 표시를 꺼도 이 명령어로 다시 켤 수 있습니다.
Mod Menu에서는 **Show Interaction → 설정 버튼**으로 같은 설정창을 열 수 있습니다. 저장하거나 취소하면 모드 목록으로 돌아갑니다.

| 항목 | 조절 방법 |
| --- | --- |
| 전체 표시 | 모든 강조를 한 번에 켜기/끄기; 반응별 설정은 보존 |
| 투명도 | 0~100% 슬라이더. 0%는 선명하게, 100%는 완전히 투명하게 표시 |
| 설치 / 제거 / 조절 / 상자 열기 / 확인 | 각 반응을 독립적으로 켜기/끄기 |
| 각 반응의 표시 시간 | 0.5~10초, 0.5초 간격으로 각각 조절 |
| 저장 후 적용 | 변경을 저장하고 즉시 적용; 기존 표식은 초기화 |
| 취소 / Esc | 변경 전 설정을 유지하고 닫기 |

설정은 재시작 후에도 유지됩니다. 상자 열기와 조절을 구분하기 위해 서버의 응답을 기다리며, 상태 변화나 화면 열기가 없는 일반 사용은 최대 1.5초 뒤 ‘확인’으로 표시할 수 있습니다. 휠 클릭 확인은 즉시 표시됩니다.

## 설정 파일

첫 실행 후 게임 프로필의 `config/show-interaction.json`이 생성됩니다. 아래 항목을 파일에서 직접 수정할 때는 게임을 종료한 뒤 수정하고 다시 실행하세요.

| 설정 | 기본값 | 의미 |
| --- | --- | --- |
| `enabled` | `true` | 전체 표시 여부 |
| `transparencyPercent` | `0` | 전체 투명도, 0~100% |
| `reactions.<반응>.enabled` | `true` | 해당 반응 표시 여부 |
| `reactions.<반응>.durationSeconds` | `2.5` | 해당 반응의 표시 시간, 0.5~10초 |
| `maxHighlights` | `64` | 동시에 보관할 표식 수, 1~256개 |
| `lineWidth` | `3.0` | 최신 표식의 윤곽 두께, 1~8 |
| `showWhenHudHidden` | `true` | F1 상태에서도 표시 |
| `placeColor` | `#73F59A` | 설치 색상 |
| `breakColor` | `#FF7777` | 제거 색상 |
| `adjustColor` | `#FFD166` | 조절 색상 |
| `openColor` | `#63D9FF` | 보관함 열기 색상 |
| `inspectColor` | `#D4B1FF` | 확인·일반 사용 색상 |

반응 이름은 `PLACE`(설치), `BREAK`(제거), `ADJUST`(조절), `OPEN`(상자 열기), `INSPECT`(확인)입니다.
0.1.0의 `durationSeconds`가 있으면 다섯 반응에 동일하게 옮겨 적용하며, 기존 켜기/끄기·색상·두께 설정은 보존합니다.
잘못된 수치와 색상은 허용 범위 또는 기본값으로 처리합니다. 표식은 현재 월드에서만 유지되며 월드 이동/종료 시 초기화합니다.

## 빌드 및 검사

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

Linux/macOS에서는 `./gradlew build`와 `./gradlew runClient`를 사용하세요.
설치 파일은 `build/libs/show-interaction-0.2.1.jar`에 생성됩니다.
빌드에는 표식 만료·재조작·최신 순서·최대 개수·상자 유지·초기화·반응별 시간·전체 및 개별 전환·투명도·설정 초안 분리·기존 시간 설정 이전 자동 검사가 포함됩니다.

실제 게임에서 확인한 항목과 미확인 범위는 [검증 기록](docs/VERIFICATION.md)에 구분하여 기록했습니다.

Mod Menu를 함께 테스트하려면 `gradlew.bat runClient -PwithModMenu`를 사용하세요.
기본 개발 실행에는 Mod Menu가 추가되지 않으며, 배포 JAR에도 내장하지 않습니다.

## 배포 파일 준비

```powershell
.\gradlew.bat prepareDistribution
```

검증을 통과한 파일이 `build/distributions/show-interaction-0.2.1-distribution.zip`으로 생성됩니다.
설치용 JAR, 사용 안내, 변경 기록, 라이선스, 제3자 고지, 파일별 SHA-256 검증값과 개발용 소스 JAR가 포함됩니다.
이 명령은 로컬 파일만 준비합니다. GitHub 공개 배포는 별도의 [릴리스 절차](docs/DISTRIBUTION.md)를 따릅니다.

## 범위 및 호환성

- 입력과 클라이언트가 확인한 상태를 사용합니다. 서버가 설치/제거 예측을 2초 안에 되돌리면 표식을 취소합니다. 다중 사용자 서버에서의 실기 검증은 아직 하지 않았습니다.
- 서버가 늦게 보내는 상태 변경과 상자 열기는 클릭 후 1.5초까지 연결합니다. 그보다 지연되면 ‘확인’ 반응으로만 표시할 수 있습니다.
- 개조된 아이템이 기본 `BlockItem.placeBlock`을 거치지 않거나 별도 화면을 여는 경우 전용 대응이 필요할 수 있습니다.
- 셰이더, 다른 렌더링 모드, Vulkan 환경은 별도 확인이 필요합니다.
- 이 모드는 Paint Chat Window와 별개의 프로젝트입니다.

구현 참고: [Fabric 26.2 월드 렌더링 문서](https://docs.fabricmc.net/develop/rendering/world).
